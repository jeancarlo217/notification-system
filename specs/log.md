## [2026-08-31] trap | `sqlite3.Connection.backup()` never returns if the source connection itself holds an open write transaction. `sqlite3_backup_step` answers `SQLITE_LOCKED` forever and CPython retries in a C loop no Python signal handler reaches: a `SIGALRM` at five seconds never fired and the process needed `SIGKILL`.
