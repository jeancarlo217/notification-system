## How to read this file

One item per line block, `B1` onward, in delivery order. Status is one of `todo`, `doing`, `done`
(with the date), or `blocked` (with the open question that gates it). Each item is delivered
test-first through the two windows (`specs/testing.md`), and its tests name the identifiers the item
cites. An item is done only when the gate is green and the fan-out ran, never when the code merely
exists. Update the status in place; this file is execution state, and the contract stays in the
foundation.
